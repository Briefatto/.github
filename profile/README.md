**Open now: [Briefatto Board](https://github.com/Briefatto/briefatto-board).** The design layer for every agent: one versioned design guide (`DESIGN.md`) read before visual work, a quality floor for every piece, and truthful status after a brand change. Apache-2.0.

```sh
npx briefatto-board install
```

Also open: **[design-md-gallery](https://github.com/Briefatto/design-md-gallery)**, 110 free DESIGN.md files for brands like Linear, Vercel, Supabase, Notion and Stripe, measured from their rendered sites and ready for every agent.
