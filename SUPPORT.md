# Support

- **Guides:** [briefatto.com/guides](https://briefatto.com/guides/) covers setup, every command and the brand files.
- **Questions:** ask in Discussions on [Briefatto Board](https://github.com/Briefatto/briefatto-board/discussions) or [design-md-gallery](https://github.com/Briefatto/design-md-gallery/discussions).
- **Bugs and requests:** open an issue in the repository it concerns.
- **Security:** report privately, as described in [SECURITY.md](https://github.com/Briefatto/.github/blob/main/SECURITY.md).
