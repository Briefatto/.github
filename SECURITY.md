# Security policy

## Report a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**.

- [Report for Briefatto Board](https://github.com/Briefatto/briefatto-board/security/advisories/new)
- [Report for design-md-gallery](https://github.com/Briefatto/design-md-gallery/security/advisories/new)

Do not open a public issue, discussion or pull request for a security problem.

Include what is affected, how to reproduce it and what an attacker gains. We confirm the report, work on the fix with you in the private advisory, and credit you when it is published unless you ask us not to.

## Scope

The code in Briefatto's public repositories and the `briefatto-board` package on npm. Fixes ship in the latest release; update to it.
